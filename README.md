# Открытки

Android-приложение для создания открыток: повод → картинка (ИИ через веб-чат, бесплатный генератор, свой API, готовые картинки, своё фото) → текст (стихи Ивана Воронцова, пожелания, ИИ, свой) → оформление → отправка.

Готовые картинки взяты с Wikimedia Commons и имеют статус общественного достояния или CC0; список с источниками — `app/src/main/assets/stock/licenses.json` и `IMAGES-LICENSES.md`.
